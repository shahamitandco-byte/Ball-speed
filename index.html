What changed in v6 + tuning

Small-ball detection fixed. The engine now reacts to the hottest small zone in each column instead of averaging the whole height — a tiny ball's signal is no longer drowned out. Processing resolution is also higher.

Watch the dots. Roll a ball across the frame: lime dots must trail it. No dots = raise sensitivity. Dots on empty air = lower it. Do this 30-second check before every session.

Live tracking counter. While a ball is in flight the status line shows "tracking: N pts". If you see the counter rise but no speed appears, tell me the number it reached — that pinpoints the remaining bottleneck.

Missed the pole? Still counted. If a solid track ends without crossing the pole, the speed is reported anyway when the ball leaves the frame.
